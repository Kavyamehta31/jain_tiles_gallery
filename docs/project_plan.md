# Jain Tiles Gallery

## Purpose

Offline Android application to manage:

- Products
- Stock
- Customer Orders

---

## Features

### Products

- Add Product
- Edit Product
- Delete Product
- Search Product
- Multiple Images

### Orders

- Customer Name
- Phone Number
- Address
- Multiple Products
- Auto Stock Reduction

### Stock

- Current Stock
- Low Stock Alert

---

## Technology

Flutter
SQLite
Image Picker
